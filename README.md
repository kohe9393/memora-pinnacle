# めくる単語帳

自分の単語帳を読み込んで、**2段階のスワイプ**で覚える単語アプリです。
答える前の「自信」と、答え始めるまでの「速さ」から苦手な単語を見つけ出し、覚えるまでくり返し出題します。

iPhone / Android のホーム画面に追加すると、アプリのように全画面・オフラインで使えます（PWA）。
サーバーやアカウントは不要で、データは端末の中だけに保存されます。

## 学び方

1. 単語を見て、答え（意味）を頭の中で思い浮かべる
2. 合っている自信をスワイプ：**右＝自信アリ／下＝まあまあ／左＝自信なし**
3. 答えが出たら、**合っていたら右／間違っていたら左**

- 間違えた単語は、5枚あとにもう一度出ます（正解するまで最大3回）
- 正解でも、答え始めるまでに **2秒以上** かかった単語は「瞬発力不足」として苦手に入ります
- 苦手な単語は、**別々の日に2回すばやく正解する** と苦手から卒業します
- 初めて見て1.5秒以内に自信アリで正解した単語は「もう知っている」として15日後まで出しません
- ↺ ボタンで1つ前の回答を取り消せます

## 読み込める形式の例

どれも「1行に単語と意味（あれば例文・メモ）」です。区切りは自動で判定されます。

```text
apple	りんご                      ← タブ区切り（Excel などからコピペ）
abandon,"捨てる, 見捨てる",He abandoned the plan.   ← CSV（3列目は例文）
take off - 離陸する                  ← ハイフン
apple: りんご                        ← コロン
give up 諦める                       ← スペースだけ（英語と日本語の境目で分けます）
1. ability 能力                      ← 番号付きリスト（番号は外します）
```

1行目が「英単語,意味,例文」のような見出しなら、列の順番も見出しに合わせます。
空行で区切ったまとまり、1行ずつ交互に書いたリスト、Quizlet・Anki の書き出し、日本語版 Excel の CSV（Shift_JIS）にも対応しています。

## iPhone で使うには

このアプリはビルド不要の静的ファイルだけでできているので、そのまま公開できます。

1. GitHub のリポジトリで **Settings → Pages** を開き、
   **Source: Deploy from a branch / Branch: `main`・`/ (root)`** を選んで保存
2. 数分後に表示される URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を iPhone の Safari で開く
3. 共有ボタン → **ホーム画面に追加**

> データは端末の中（ブラウザの保存領域）にあります。機種変更の前などは、設定画面の「バックアップを書き出す」で保存してください。

## 次に出す日の決め方（`js/srs.js`）

- 間隔は「日」で持ち、伸ばす土台は **実際にあいた日数** です（前倒しで解いても間隔が飛びすぎない）
- 自信アリですばやく正解するたびに、単語ごとの「覚えやすさ（最初 2.5）」が上がり、間隔が 2日 → 4日 → 11日 → 1か月 → 3か月 … と伸びます（期限の日に答えた場合）
- まあまあの正解は伸びを 0.75 倍に、自信なしの正解は当てずっぽうかもしれないので翌日また出します
- 間違えると「覚えやすさ」が下がり、翌日いちばん先に出ます
- 状態は **未学習／学習中／苦手／覚えた（間隔7日以上）** の4つ。カードの5つのドットは、間隔 1・3・7・15・30日に届くと埋まります

## 開発

依存パッケージはありません。Node.js 18 以上でテストを実行できます。

```sh
npm test          # 単体テスト（読み込み・記憶の計算・出題・保存など）
npm start         # http://localhost:8080 でアプリを起動（Python 3 を使用）
```

ファイルを変更して公開するときは、`sw.js` の `CACHE` の番号を上げると、利用者の端末でも新しい版に入れ替わります。
`js/` にファイルを追加したら `sw.js` の `ASSETS` にも追加してください（テストで確認しています）。

```
index.html            画面の土台
css/style.css         デザイン（ライト／ダーク）
js/app.js             画面の切り替え・起動
js/parser.js          単語リストの読み取り（CSV・貼り付け・文字コード判定）
js/srs.js             自信×正誤×速さから次に出す日を決める・苦手の判定
js/queue.js           出題の選び方（自動出題・スキミング・苦手・セクション）
js/session.js         学習中の進行（5枚あとの再出題・2周目・取り消し）
js/quiz.js            4択の選択肢づくり
js/analytics.js       分析画面の集計（カレンダー・苦手の内訳）
js/store.js           端末への保存・取り消し・バックアップ
js/swipe.js           カードのスワイプ操作（右・左・下）
js/views/             各画面
sw.js                 オフライン対応
tests/                単体テスト
```
